    config

    config: { [key: string]: unknown }

    Resolved variation configuration keyed by config name. Each entry arrives wrapped as { value: <resolved value> }; read it via config['<key>']?.value. Values are experiment-defined (unknown) — narrow before use, and read .value rather than testing the entry directly (the wrapper object is always truthy, even for value: false).

    Always a non-null object: the Experiment model normalizes an absent or null server config to an empty object ({}), so reading config['<key>'] never throws.
